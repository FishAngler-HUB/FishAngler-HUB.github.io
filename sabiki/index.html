サビキ釣りとは

サビキ釣りは、アミエビを入れたカゴと複数の疑似針を使い、堤防近くを回遊するアジ、イワシ、サバなどを狙う釣りです。仕掛けを足元へ下ろせるため家族でも始めやすい釣りです。

主なターゲットはアジ・イワシ・サバなどです。このページでは初めて道具を揃える人が迷わないよう、既存の初心者向け仕様を基準に説明します。

各道具の選び方とおすすめの理由

ロッド：3〜3.3m / 磯竿2号

持ち運びやすく、サビキ釣りをはじめ堤防釣り全般に使いやすい万能ロッド。 対応する仕掛けの重さと持ちやすさも購入前に確認しましょう。

リール：2500〜3000番クラス

エサ釣りで扱いやすく、コスパに優れたスピニングリールが中心。 ロッドとの重さのバランスと必要な糸巻き量を確認します。

メインライン：ナイロン 2〜3号

扱いやすく初心者向けの太さ 扱う仕掛けに合う号数を選び、傷や劣化を釣行ごとに確認します。

リーダー：基本不要

サビキ仕掛けに内蔵されているため通常は不要 釣り場の障害物や対象魚の大きさに合わせて調整します。

ルアー・仕掛け：サビキ仕掛け3〜6号＋オモリ付き下カゴ

対象魚のサイズに合わせて針を選択 まずは基準となる重さ・サイズを用意し、状況に応じて増やします。

サビキ釣りの基本的な仕掛け

初心者が最初に覚えたい接続順です。釣行前に結び目、針、金具の傷や変形がないか確認します。

  1. ロッド＋リール
  2. ナイロンライン
  3. サビキ仕掛け
  4. オモリ付き下カゴ（アミエビを入れる）

その他に必要な小物

最初から用意したいもの

  • オモリ付き下カゴ
  • アミエビ（寄せエサ）
  • 水くみバケツ
  • 魚つかみ
  • 針外し
  • ハサミ
  • ライフジャケット

あると便利なもの

  • クーラーボックス＋氷
  • タオル
  • 竿受け

釣り場に合うライフジャケットと滑りにくい靴を用意し、立入禁止場所には入らないでください。

初心者向け・基本的な釣り方

  1. 仕掛けを絡ませないよう順に伸ばす安全と周囲を確認してから始めます。
  2. 下カゴへアミエビを入れる一つずつ動作を繰り返し、反応が出た条件を覚えます。
  3. 足元へゆっくり仕掛けを下ろす一つずつ動作を繰り返し、反応が出た条件を覚えます。
  4. 竿を軽く上下して寄せエサを出す一つずつ動作を繰り返し、反応が出た条件を覚えます。
  5. アタリが続く深さを覚えて繰り返す魚と仕掛けを安全に扱い、無理な取り込みは避けます。

おすすめの時期・状況

春から秋に小魚の回遊が多く、特に夏から秋は始めやすい時期です。朝夕まずめや潮が動く時間に、足元で魚影が見える堤防を選びます。

仕掛け・カゴ・アミエビ・針サイズ

初心者はオモリ付き下カゴと完成サビキ仕掛けを使います。針は小魚なら3〜4号、少し大きければ5〜6号が目安です。カゴへアミエビを詰めすぎず、仕掛けと同じ深さに寄せエサを広げます。

季節や適した仕掛けは地域・水深・潮・船宿のルールで変わります。現地情報を確認して調整してください。

初心者が最初に選ぶならこの構成

3〜3.3mの磯竿＋2500番リール＋下カゴ式サビキを基準にしてください。

足元に仕掛けを下ろす、下カゴ式のサビキから。 最初から多くの道具を揃えすぎず、この一式で基本操作を繰り返してから必要な重さや種類を追加すると選びやすくなります。
