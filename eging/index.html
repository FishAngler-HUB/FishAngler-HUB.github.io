エギングとは

エギングは、エビや小魚を模した「エギ（餌木）」を動かしてアオリイカを狙う釣りです。堤防や漁港から始めやすく、シャクリでエギを跳ね上げ、フォール中に抱かせます。

主なターゲットはアオリイカです。このページでは初めて道具を揃える人が迷わないよう、既存の初心者向け仕様を基準に説明します。

初心者向けエギングタックル一式

FIRST CHOICE8.3ft前後のMLロッド＋2500番リール

まずは足場のよい堤防で、2.5〜3号のエギから。 道具同士の対応重量とライン号数を確認して揃えましょう。

ロッド8.3ft前後 / MLクラス

扱いやすい入門向けの長さ。2.5〜3.5号のエギを中心に秋イカから対応。

リール2500〜C3000番

エギングで扱いやすいサイズ。PE0.6号との組み合わせに適する。

メインラインPE 0.6〜0.8号

扱いやすさと強度のバランスを重視した標準的な太さ。

リーダーフロロ 2〜2.5号 / 約1.5m

根ズレやエギの操作を考慮した標準的な太さ。

ルアー・仕掛けエギ 2.5〜3.5号

秋の小型〜中型のアオリイカを中心に幅広く対応。

各道具の選び方とおすすめの理由

ロッド：8.3ft前後 / MLクラス

扱いやすい入門向けの長さ。2.5〜3.5号のエギを中心に秋イカから対応。 対応する仕掛けの重さと持ちやすさも購入前に確認しましょう。

リール：2500〜C3000番

エギングで扱いやすいサイズ。PE0.6号との組み合わせに適する。 ロッドとの重さのバランスと必要な糸巻き量を確認します。

メインライン：PE 0.6〜0.8号

扱いやすさと強度のバランスを重視した標準的な太さ。 扱う仕掛けに合う号数を選び、傷や劣化を釣行ごとに確認します。

リーダー：フロロ 2〜2.5号 / 約1.5m

根ズレやエギの操作を考慮した標準的な太さ。 釣り場の障害物や対象魚の大きさに合わせて調整します。

ルアー・仕掛け：エギ 2.5〜3.5号

秋の小型〜中型のアオリイカを中心に幅広く対応。 まずは基準となる重さ・サイズを用意し、状況に応じて増やします。

エギングの基本的な仕掛け

初心者が最初に覚えたい接続順です。釣行前に結び目、針、金具の傷や変形がないか確認します。

  1. ロッドにリールを付ける
  2. PEライン
  3. リーダーを結ぶ
  4. スナップ
  5. エギ

まずは足場のよい堤防で、2.5〜3号のエギから。

その他に必要な小物

最初から用意したいもの

  • PEライン対応ハサミ
  • エギ用スナップ
  • タモ（足場の高さに合う長さ）
  • エギケース
  • ライフジャケット

あると便利なもの

  • イカ締めピック
  • ジップ袋
  • クーラーボックス＋保冷剤
  • 偏光グラス

釣り場に合うライフジャケットと滑りにくい靴を用意し、立入禁止場所には入らないでください。

初心者向け・基本的な釣り方

  1. 周囲を確認して沖へ投げる安全と周囲を確認してから始めます。
  2. ラインを見ながら着底まで沈める一つずつ動作を繰り返し、反応が出た条件を覚えます。
  3. ロッドを2〜3回軽くシャクる一つずつ動作を繰り返し、反応が出た条件を覚えます。
  4. ラインを張りすぎずフォールさせる一つずつ動作を繰り返し、反応が出た条件を覚えます。
  5. 重みや違和感が出たら合わせて巻く魚と仕掛けを安全に扱い、無理な取り込みは避けます。

おすすめの時期・状況

岸から狙いやすい代表的な季節は春と秋です。地域や水温によって時期が違うため、釣行前に地域の釣果と規制を確認します。

春イカと秋イカの違い

秋は小型が多く2.5〜3号が扱いやすい季節です。春は大型を3.5号で狙う場面が増え、藻場や深場をゆっくり探ります。初回は反応を得やすい秋がおすすめです。

季節や適した仕掛けは地域・水深・潮・船宿のルールで変わります。現地情報を確認して調整してください。

初心者が最初に選ぶならこの構成

8.3ft前後のMLロッド＋2500番リールを基準にしてください。

まずは足場のよい堤防で、2.5〜3号のエギから。 最初から多くの道具を揃えすぎず、この一式で基本操作を繰り返してから必要な重さや種類を追加すると選びやすくなります。
